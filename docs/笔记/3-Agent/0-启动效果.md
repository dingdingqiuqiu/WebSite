### 命令

后端

```bash
cd pudding-java
cp .env.example .env        # 填入你自己的 API Key
docker compose up -d --build
docker compose ps
docker compose logs -f pudding-java
```

前端

```bash
cd pudding-frontend
pnpm run dev
```
