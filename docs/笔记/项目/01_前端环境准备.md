### 本地nginx运行前端工程即可

前端工程所处位置

![image-20260831122818670](assets/01_前端环境准备/image-20260831122818670.png)

进入`nginx.exe`所在目录后命令行运行`nginx.exe`即可

```bash
start .\nginx.exe
```

运行后访问http://localhost:8080/有回显
