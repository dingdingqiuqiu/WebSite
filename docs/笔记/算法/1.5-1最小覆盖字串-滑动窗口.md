# 76.最小覆盖子串

## 76.最小覆盖字串

[力扣题目链接](https://leetcode.cn/problems/minimum-window-substring/)

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 子串**，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串 `""`。

测试用例保证答案唯一。 

**示例 1：**

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

**示例 2：**

```
输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
```

**示例 3:**

```
输入: s = "a", t = "aa"
输出: ""
解释: t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。
```

**提示：**

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 105`
- `s` 和 `t` 由英文字母组成

**进阶：**你能设计一个在 `O(m + n)` 时间内解决此问题的算法吗？

## 算法思路

> 滑动窗口本质枚举了每个 `right` 作为区间右端点时，满足条件的最短区间。
>
> 因为前一个`left`和`right`已知最短区间，满足大于`target`的条件
>
> 所以后一个`right`（正数）加进来后，前一个`left`和后一个`target`一定也满足大于`target`的条件
>
> 因此只需要尝试`left`右移即可
>
> 以上即为滑动窗口（双指针）为什么有效的原因

本题核心思想依旧是右指针加入新的一定满足`target`，实际上在右指针不动的基础上向右移动左指针直到满足“最小”

对于字符是否存在的快捷搜索，我们可以借助哈希表的思想，不过我们这里对哈希表进行了“改良” 使用`need[]`数组表示每个位置还差多少满足要求，注意`need[]`数组仅作快速搜索使用，不使用`need[]`数组判断是否满足条件

```bash
need[ch] = ch位置上需要的数量 - 目前窗口中ch有的数量
```

> 不光要关注需要的还差多少 多的我们也应该记录为负数 意思是只要我们移动左右指针 
>
> `need`数组一定要随着左右指针的移动变化
>
> 例如t = "ABC"，s = "AABC"，s中第二个'A'我们记录-1后，左指针右移还能给加回来

同时我们引入辅助变量`total`表示当前还差几个字符可以完成要求 ，`total`在运行过程中全程为自然数，当且仅当`total`为0时我们得以快速判断满足条件，此时我们尝试收缩左边界，如果发现左边界对应的`need`值恰好为0，此时意味着刚好满足条件，继续收缩将退出循环，此时给`total++`使得退出循环

## 实际解决

```java
class Solution {
    public String minWindow(String s, String t) {
        // 特殊情况 不必额外判断 直接返回空
        if (s == null || t == null || s.length() == 0 || t.length() == 0 || s.length() < t.length()) {
            return "";
        }

        // 定义需要用到的所有变量
        // 滑动窗口的左右指针
        int left = 0, right = 0;
        // 最小字串的起始位置及其长度
        int minStart = 0, minLen = Integer.MAX_VALUE;
        // 字符串s和t的长度
        int m = s.length(), n = t.length();
        // 用数组代替哈希表完成相应功能 128可以覆盖所有大小写英文字符
        // 设计哲学为 need[ch] = ch位置上需要的数量 - 目前窗口中ch有的数量
        int [] need = new int[128];
        // 字符串t的长度 为需要匹配的字符数 仅当total为0时子字符串满足条件 此时收缩左边界直到满足最小
        int total = n;
        // 完成对哈希表的初步构建 char位置上值大于0代表存在该字符 哈希表仅辅助搜索 不作为判断是否满足条件的依据
        for (int i = 0; i < n; i++) {
            need[t.charAt(i)]++;
        }

        // 主循环 滑动窗口退出的条件是右指针搜索到m
        while (right < m) {
            // 哈希表快速搜索找到了满足需要的字符
            if (need[s.charAt(right)] > 0) {
                // 找到满足需要的 总共需要找的字符自然减一
                total--;
            }
            // 无论找没找到都要对应位置-- t = "ABC"，s = "AABC" 第二个A要置为-1
            need[s.charAt(right)]--;
            // 满足条件但非最小时尝试收缩左边界直到不满足条件
            while (total == 0) {
                // 尝试更新最小值
                if (right - left + 1 < minLen) {
                    minLen = right - left + 1;
                    minStart = left;
                }
                // 当最左边的left指向的值恰好满足条件时 再移动left会导致条件不满足 从而退出循环 指针指向新left
                if (need[s.charAt(left)] == 0) {
                    total++;
                }
                // 更新need数组及左边界
                need[s.charAt(left)]++;
                left++;
            }
            // 找到前一个right的最优解后找下一个right的最优解
            right++;
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(minStart, minStart + minLen);
    }
}
```
