# 215.数组中第K个最大元素

## 215.数组中第K个最大元素

[力扣题目链接](https://leetcode.cn/problems/kth-largest-element-in-an-array/description/)

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1:**

```
输入: [3,2,1,5,6,4], k = 2
输出: 5
```

**示例 2:**

```
输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4 
```

**提示：**

- `1 <= k <= nums.length <= 105`
- `-104 <= nums[i] <= 104`

## 算法思路

> **分区不是排序，只做一件事：选一个基准 `pivot`，把“该在左边”的元素放到左边，把“该在右边”的元素放到右边，并确定 `pivot` 的最终下标。**

你要找第 `k` 大，所以按**降序**分：  
- 左边元素都 `>= pivot`
- 右边元素都 `<= pivot`
- `pivot` 落在分界点

我们核心只需要实现：把每次传进来的数组的最左边元素作为基准，将该基准的最终下标返回给调用它的函数

### 用“挖坑法”想分区

降序分区目标是：

```text
[  >= pivot 的元素 ]  pivot  [  <= pivot 的元素 ]
```

我们先把 `pivot` 的值保存起来：

```java
int pivot = nums[left];
```

此时 `nums[left]` 这个位置就可以看成“一个坑”，因为 `pivot` 的值已经在变量里了。

然后：

- 从右往左找：找到第一个 `> pivot` 的数，它应该在左边，把它填到左边的坑里。
- 从左往右找：找到第一个 `< pivot` 的数，它应该在右边，把它填到右边的坑里。
- 重复，直到 `i == j`。
- 最后把 `pivot` 放进最后的坑。

口诀：

> **降序分区：右找大，填左；左找小，填右；最后放基准。**

```java
private int partitionDesc(int[] nums, int left, int right) {
    int pivot = nums[left];

    int i = left;
    int j = right;

    while (i < j) {
        // 右边本来应该放 <= pivot 的数，所以跳过它们
        // 找到第一个 > pivot 的数
        while (i < j && nums[j] <= pivot) {
            j--;
        }

        // 把右边这个“该去左边”的数，填到左边的坑里
        if (i < j) {
            nums[i] = nums[j];
            i++;
        }

        // 左边本来应该放 >= pivot 的数，所以跳过它们
        // 找到第一个 < pivot 的数
        while (i < j && nums[i] >= pivot) {
            i++;
        }

        // 把左边这个“该去右边”的数，填到右边的坑里
        if (i < j) {
            nums[j] = nums[i];
            j--;
        }
    }

    // 最后 i == j，这个位置就是 pivot 的最终位置
    nums[i] = pivot;
    return i;
}
```

注意几个点：

1. `pivot` 的值已经保存，所以 `nums[left]` 可以当作坑。
2. 每次填坑后，另一个位置变成新坑。
3. 最后 `i == j`，把 `pivot` 放进最后的坑。这里通过每次改变位置保证：**`i < j`**实现 因此极端情况下最终只能`i == j`
4. 等于 `pivot` 的元素用 `<=`、`>=` 跳过，不来回搬，逻辑更稳。

## 5. 完整快速选择代码

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 降序分区后，第 k 大元素的下标是 k - 1
        return quickSelect(nums, 0, nums.length - 1, k - 1);
    }

    private int quickSelect(int[] nums, int left, int right, int target) {
        if (left == right) {
            return nums[left];
        }

        int p = partitionDesc(nums, left, right);

        if (p == target) {
            return nums[p];
        } else if (target < p) {
            return quickSelect(nums, left, p - 1, target);
        } else {
            return quickSelect(nums, p + 1, right, target);
        }
    }

    private int partitionDesc(int[] nums, int left, int right) {
        int pivot = nums[left];
        int i = left;
        int j = right;

        while (i < j) {
            // 从右往左，跳过本来就该在右边的元素：<= pivot
            while (i < j && nums[j] <= pivot) {
                j--;
            }

            // 找到一个 > pivot 的，把它填到左边坑
            if (i < j) {
                nums[i] = nums[j];
                i++;
            }

            // 从左往右，跳过本来就该在左边的元素：>= pivot
            while (i < j && nums[i] >= pivot) {
                i++;
            }

            // 找到一个 < pivot 的，把它填到右边坑
            if (i < j) {
                nums[j] = nums[i];
                j--;
            }
        }

        // i == j，pivot 的最终位置
        nums[i] = pivot;
        return i;
    }
}
```

## 6. 最后总结

你只要抓住这几点，这块就不会乱：

1. 第 `k` 大，降序后下标是 `k - 1`。
2. 降序分区：左边大，右边小。
3. 右边找 `> pivot` 的，搬到左边。
4. 左边找 `< pivot` 的，搬到右边。
5. 等于 `pivot` 的不搬，用 `<=`、`>=` 跳过。
6. 挖坑法最后一定是 `nums[i] = pivot; return i;`。
7. 快速选择只递归目标所在的一侧，不需要把数组完整排好。

记住口诀：

> **降序分区：右找大填左，左找小填右，最后放基准。**

因为这段代码里，**所有会让 `i`、`j` 移动的地方，都保证了它们不会越过对方**。

看外层：

```java
while (i < j) {
    ...
}
```

只要进入循环，就有 `i < j`。

再看里面的移动：

```java
while (i < j && nums[j] <= pivot) {
    j--;
}
```

这个 `while` 自带 `i < j`，所以 `j` 最多减到 `j == i`，不会变成 `j < i`。

```java
while (i < j && nums[i] >= pivot) {
    i++;
}
```

同理，`i` 最多加到 `i == j`，不会变成 `i > j`。

填坑时：

```java
if (i < j) {
    nums[i] = nums[j];
    i++;
}
```

这里先判断 `i < j`，然后 `i++`。  
因为原来 `i < j`，也就是 `i` 至少比 `j` 小 1，所以 `i++` 后最多变成 `i == j`，不会 `i > j`。

另一边：

```java
if (i < j) {
    nums[j] = nums[i];
    j--;
}
```

同理，`j--` 后最多变成 `j == i`，不会 `j < i`。

---

所以整个过程指针只会：

- 从两边向中间靠拢；
- 每次最多靠拢到相遇；
- 不会越过对方。

因此外层 `while (i < j)` 退出时，只可能是：

```text
i == j
```

不可能是 `i > j`。

---

你可以这样理解：

> `i` 和 `j` 像两个人从数组两端往中间走，规则规定“碰到对方就停”，所以最后一定停在同一个位置，而不是一个走过对方。

---

### 对比：什么时候会出现 `i > j`？

如果内层 `while` 不写 `i < j`，例如：

```java
while (nums[j] <= pivot) {
    j--;
}
```

或者填坑时不小心多移动一次：

```java
i++;
j--;
```

就可能出现 `i > j`，甚至数组越界。

所以这里最后一定是 `i == j`，不是巧合，而是因为：

```java
while (i < j && ...)
if (i < j) { ... i++; }
if (i < j) { ... j--; }
```

这些条件共同保证了指针**只相遇，不交叉**。

最后：

```java
nums[i] = pivot;
return i;
```

此时 `i == j`，这个重合的位置就是 `pivot` 的最终位置。







## 实际解决

```cpp
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 哈希集合，记录每个字符是否出现过
        Set<Character> set = new HashSet<Character>();
        int n = s.length();
        int right = 0,left = 0, ans = 0;
        // 遍历left
        while (left < n) {
            // 持续往后移动right 直到不满足条件
            while (right < n && !set.contains(s.charAt(right))) {
                // 不断地移动右指针
                set.add(s.charAt(right));
                ++right;
            }
            // 第 left 到 right 个字符是一个极长的无重复字符子串
            ans = Math.max(ans, right - left);
            // 下一轮循环
            set.remove(s.charAt(left));
            left++;
        }
        return ans;
    }
}
```

    }
}

最快解法参考

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        char []chars = s.toCharArray();
        int []map = new int[128];
        int left = 0; int right = 0; int ans = 0;
        int n = s.length();
        while (right < n) {
            // 必须移动左指针到满足条件
            while (map[chars[right]] > 0) {
                map[chars[left]]--;
                left++;
            }
            map[chars[right]]++;
            right++;
            ans = ans > right - left ? ans : right - left;
        }
        return ans;
    }
}
```
