# 3.无重复字符的最长子串

## 3.无重复字符的最长子串

[力扣题目链接](https://leetcode.cn/problems/minimum-size-subarray-sum/)

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

**示例 1:**

```
输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
```

**示例 2:**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3:**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

**提示：**

- `0 <= s.length <= 105`
- `s` 由英文字母、数字、符号和空格组成

## 算法思路

遍历以left为左端点的最长子串长度即可 持续右移直到不满足条件

## 实际解决

```cpp
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 哈希集合，记录每个字符是否出现过
        Set<Character> set = new HashSet<Character>();
        int n = s.length();
        int right = 0,left = 0, ans = 0;
        // 遍历left
        while (left < n) {
            // 持续往后移动right 直到不满足条件
            while (right < n && !set.contains(s.charAt(right))) {
                // 不断地移动右指针
                set.add(s.charAt(right));
                ++right;
            }
            // 第 left 到 right 个字符是一个极长的无重复字符子串
            ans = Math.max(ans, right - left);
            // 下一轮循环
            set.remove(s.charAt(left));
            left++;
        }
        return ans;
    }
}
```

另一种解法

```java
 class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 哈希集合，记录每个字符是否出现过
        Set<Character> set = new HashSet<Character>();
        int n = s.length();
        int right = 0,left = 0, ans = 0;
        // 遍历left
        // [left,right)
        while (right < n) {
            while (set.contains(s.charAt(right))) {
                set.remove(s.charAt(left));
                left++;
            }
            set.add(s.charAt(right));
            ++right;
            ans = Math.max(ans, right - left);
        }
        return ans;
    }
}
```

最快解法参考

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        char []chars = s.toCharArray();
        int []map = new int[128];
        int left = 0; int right = 0; int ans = 0;
        int n = s.length();
        while (right < n) {
            // 必须移动左指针到满足条件
            while (map[chars[right]] > 0) {
                map[chars[left]]--;
                left++;
            }
            map[chars[right]]++;
            right++;
            ans = ans > right - left ? ans : right - left;
        }
        return ans;
    }
}
```
