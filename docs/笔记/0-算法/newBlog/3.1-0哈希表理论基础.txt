## 哈希表

### 哈希表的概念

哈希表是一种数据结构，可以理解为一个数组，通过关联码，即数组下标索引直接访问数组元素。

一般哈希表都是用来快速判断一个元素是否出现在集合里。

### 哈希函数

把值转化成下标索引的函数即为哈希函数。例如可以把学生姓名映射为哈希表的下标，通过下标直接访问所在下标的值即可快速查询该同学是否在这所学校中。

### 哈希碰撞

那么这么就产生了一个问题，不过不同的值映射到了同一数组下标，例如小李和小王的名字都映射到了数组下标为1的位置，这种现象就叫做哈希碰撞。解决哈希碰撞的方法有两种:拉链法和线性探测法。

### 哈希表的常见结构

我们想使用哈希法来解决问题的时候，我们一般会选择如下三种数据结构。

1. 数组
2. set（集合）
3. map(映射)

#### 1.数组

利用数组实现哈希表没什么好说的，主要难度是把不同的值映射为不同的数组下标。例如统计字符时可以开一个128大小的数组，直接用ascii码表示的数组下标计数；倘若仅有小写字母，可以开一个26大小的数组，使用`char-'a'`作为数组下标。

#### 2.set集合

其本质是一个不包含重复元素的集合，内部通常用哈希表实现（Java中的HashSet底层就是HashMap，只使用键，值用一个哑对象）。

当你只关心某个元素是否存在，不关心它出现多少次或关联什么值时，用Set。
例：去重、判断一个单词是否在字典中、记录访问过的节点等。
  ```java
  Set<String> visited = new HashSet<>();
  visited.add("A");
  if (visited.contains("A")) { ... }
  ```
  
  常见实现：
  · HashSet：无序，O(1)操作。
  · LinkedHashSet：维护插入顺序（双向链表），O(1)操作但稍慢。
  · TreeSet：基于红黑树，有序，O(log n)操作（不是哈希实现，但常被对比）。
