## 1. 哈希表基础

其本质就是一个数组，用`key`作为下标访问数组的`value`

接下来是常见的三种哈希结构：

- 数组
- set（集合）
- map（映射）

另外哈希有个问题是哈希碰撞，解决方法：

1. 链表法
2. 线性探测法

## 2. 数组作为哈希表

适用情况：

1. key的范围固定。例如：题目只包含小写字母/大小写字母和数字

使用方式

2. 关键是找到一个合适的`key`。有些需要排序变换后统一一个`key`

## 3. set作为哈希表

适用情况

1. key的范围很大
2. 无记录额外数据的要求，仅判定是否出现过

## 4.map作为哈希表

适用情况

1. key的范围很大
2. 需要额外记录出现次数或者其他变量

## 5. 双指针解决多数之和（去重）

1. 两数之和

   遍历一遍，看有没有`target-x`在哈希表中，如果没有，就放入哈希表中，并把下标作为`value`,如果有`target-x`作为`key`在哈希表中，就直接返回答案，因为仅遍历一次 复杂度为O(n）

2. 三数之和

   因为n^2的复杂度大于nlogn 所以我们可以引入`Arrays.sort()`进行快排后再利用双指针把原本的n^3 降到 n^2 ;双数之和因为排序nlongn复杂度大于n,所以我们直接遍历写入哈希表，不引入`Arrays.sort()`；

   具体的操作思路是先排序，固定一个值，双指针分别在最左边和最右边，根据结果的大小选择移动左指针还是右指针

   剪枝：当第一个值大于0时，后面两个加起来肯定更大于0；可以`break`剪枝

   去重：第一个值的下边大于0并且与前一个值相等`i > 0 && nums[i] == nums[i-1]` 去重`continue`;

   **找到一个结果后**，对左右指针进行去重：

   `while(left < right && nums[left] == nums[left+1]) left++;`

   `while(left < right && nums[right] == nums[right-1]) right--;`

3. 四数之和

   三数之和是固定一个值，四数之和是在三数之和基础上再套一个`for`循环；也就是固定两个数

   同样先排序

   剪枝：

   第一层：`nums[i] > target && nums[i] >= 0`,后面加起来一定不会满足等于`target`了，`break`

   第二层：`nums[i] + nums[j] > target && nums[j] >= 0` ,后面加起来一定不会满足等于`target`了，`break`

   去重：

   第一层：`i > 0 && nums[i] == nums[i-1]` continue 去重

   第二层：`j > i+1 && nums[j] == nums[j-1]` continue 去重

   **找到结果后**，对左右指针去重

   `while(left < right && nums[left] == nums[left+1]) left++;`

   `while(left < right && nums[right] == nums[right-1]) right--;`

4. 四数之和2

   遍历A和B,把A和B组合的所有相加的可能性存入哈希表，`key`为相加的值，`value`是出现的次数

   遍历C和D，如果发现`-(C+D)`为`key`在哈希表中，把`value`取出来加入`result`中

   关键差别是本题为四个独立的数组，只要找到A[i] + B[j] + C[k] + D[l] = 0就可以，不用考虑重复问题，而普通四数之和，三数之和是一个数组（集合）里找到和为0的组合，可就难很多了。
