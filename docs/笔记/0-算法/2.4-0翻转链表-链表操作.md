# 206.反转链表

## 206.反转链表

[力扣题目链接](https://leetcode.cn/problems/design-linked-list/description/)

题意：反转一个单链表。

示例: 输入: 1->2->3->4->5->NULL 输出: 5->4->3->2->1->NULL

## 算法思路

思路上比较基础 主要可以借助多个指针 通过改变`next`指针的朝向 可以不借助额外的内存空间 在原地实现对链表的翻转 注意在改变`cur`的`next`的朝向之前先使用`tmp`保存`tmp`的原`next`朝向。

### 实现

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode pre = null;
        ListNode cur = head;
        ListNode tmp = null; // 这里主要怕head == null 不直接 cur.next
        while (cur != null) {
            tmp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = tmp;
        }
        return pre;
    }
}
```
