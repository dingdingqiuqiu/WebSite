# 179.最大数

## 179.最大数

[力扣题目链接](https://leetcode.cn/problems/largest-number/description/)

给定一组非负整数 `nums`，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数。

**注意：**输出结果可能非常大，所以你需要返回一个字符串而不是整数。

**示例 1：**

```
输入：nums = [10,2]
输出："210"
```

**示例 2：**

```
输入：nums = [3,30,34,5,9]
输出："9534330"
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 109`

## 算法思路

本质是排序，我们可以定义排序规则，底层排序过程由`Arrays.sort()`调用归并/快排自动帮我们完成

```java
 // 若 b+a > a+b，说明 b 放前面更大 → b 排前
Arrays.sort(strs, (a, b) -> (b + a).compareTo(a + b));
```

其中`compareTo`的底层实现如下：

> 虽然是字符串，但实现了大小比较的功能

```java
public int compareTo(String other) {
    int len = Math.min(this.length(), other.length());
    for (int i = 0; i < len; i++) {
        char c1 = this.charAt(i);
        char c2 = other.charAt(i);
        if (c1 != c2) {
            return c1 - c2;          // 第一个不同字符，直接相减返回
        }
    }
    return this.length() - other.length();  // 前缀都相同，短的排前面
}
```

**细节详解**

```java
Arrays.sort(T[] a, Comparator<? super T> c)
```

传入一个数组，一个实现了 `Comparator` 接口的对象，排序时能调用它的 `compare(a, b)`。

```java
Arrays.sort(strings, (a, b) -> (b + a).compareTo(a + b));
```

等价于匿名内部类写法：

```java
Arrays.sort(strings, new Comparator<String>() {
    @Override
    public int compare(String a, String b) {
        return (b + a).compareTo(a + b);
    }
});
```

这里：

- `new Comparator<String>() { ... }` 创建了一个 **Comparator 对象**；
- `compare` 方法就是比较规则；
- `Arrays.sort` 拿到这个对象后，内部反复调用 `compare(x, y)`。

运行时`sort`的联动大概类似一下代码

> 所以只需要实现`Comparator`接口通过返回数字大小判断谁在前面即可

```java
// Arrays.sort 内部类似：
Comparator<String> c = (a, b) -> (b + a).compareTo(a + b);

int result = c.compare(x, y);

if (result < 0) {
    // x 排 y 前面
} else if (result > 0) {
    // y 排 x 前面
}
```

## 实现

写法一（Lambda，直观但每次比较 new 两个 String）：

```java
class Solution {
    public String largestNumber(int[] nums) {
        String[] strings = new String[nums.length];
        for (int i = 0; i < nums.length; i++) {
            strings[i] = String.valueOf(nums[i]);
        }
        Arrays.sort(strings, (a , b) -> (b+a).compareTo(a+b));
        if (strings[0].equals("0")) { // 特殊情况：数组为全0数组
            return "0";
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < strings.length; i++) {
            sb.append(strings[i]);
        }
        return sb.toString();
    }
}
```

写法二（零分配写法（大数组推荐，不在比较器里造 String））

```java
class Solution {
    public String largestNumber(int[] nums) {
        int n = nums.length;
        String[] strs = new String[n];
        for (int i = 0; i < n; i++) strs[i] = String.valueOf(nums[i]);

        Arrays.sort(strs, Solution::cmp);

        if (strs[0].equals("0")) return "0";

        StringBuilder sb = new StringBuilder(n * 10);
        for (String s : strs) sb.append(s);
        return sb.toString();
    }

    /** 比较 b+a 与 a+b：返回 >0 表示 a 应排在 b 后面（即 b 放前面更大） */
    private static int cmp(String a, String b) {
        int la = a.length(), lb = b.length(), total = la + lb;
        for (int i = 0; i < total; i++) {
            char c1 = i < lb ? b.charAt(i) : a.charAt(i - lb);   // b+a 的第 i 位
            char c2 = i < la ? a.charAt(i) : b.charAt(i - la);   // a+b 的第 i 位
            if (c1 != c2) return c1 - c2;
        }
        return 0;
    }
}
```
