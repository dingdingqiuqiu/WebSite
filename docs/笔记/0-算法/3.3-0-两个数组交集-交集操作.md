# 349. 两个数组的交集

## 349.两个数组的交集

[力扣题目链接](https://leetcode.cn/problems/intersection-of-two-arrays/)

给定两个数组 `nums1` 和 `nums2` ，返回 *它们的 交集* 。输出结果中的每个元素一定是 **唯一** 的。我们可以 **不考虑输出结果的顺序** 。

**示例 1：**

```
输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]
```

**示例 2：**

```
输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]
解释：[4,9] 也是可通过的
```

**提示：**

- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 1000`

## 算法思路

由于结果也需要去重，我们定义结果`HashSer res` ,遍历一遍`nums1`,构建得到一个`HashSet set`,遍历`nums2`，如果`nums2`中元素在`HashSet`中，加入结果`HashSet`,最后通过流把`Integer`转成`Int`输出即可，也可以新开一个`res.size`的数组复制出来。

更巧妙的思路是利用题目的数据范围开一个`boolean`类型的数组`array`，将`nums1`的值作为下标置`array`的值为`true`，在遍历`nums2`时，一旦访问到`array[x]`为`true`时，**自动将该值改为`false`**从而实现单次访问（驱虫）

## 实现

```java
class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        Set<Integer> set = new HashSet<>();
        Set<Integer> res = new HashSet<>();
        for (int i = 0; i < nums1.length; i++) {
            set.add(nums1[i]);
        }
        for (int i = 0; i < nums2.length; i++) {
            if (set.contains(nums2[i])) {
                res.add(nums2[i]);
            }
        }

        int[] resArr = new int[res.size()];
        int i = 0;
        for (int x : res) {
            resArr[i++] = x;
        }
        return resArr;

        // 用流更慢
        // return res.stream().mapToInt(x -> x).toArray();
    }
}
```

数组法：

```java
class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        boolean []array = new boolean[1001];
        for (int x : nums1) array[x] = true;
        int []res = new int[1001];
        int index = 0;
        for (int x : nums2) {
            if (array[x]) {
                array[x] = false;
                res[index++] = x;
            }
        }
        return Arrays.copyOf(res, index);
    }
}
```
